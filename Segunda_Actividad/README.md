# Segunda Actividad

Desarrollo de las actividades de Microcontroladores utilizando ESP32, MicroPython, Wokwi y YOLO.

## Actividades

### 01 - Wokwi y MicroPython
Desarrollo y simulación de un circuito con ESP32 utilizando Wokwi y MicroPython.

### 02 - YOLO
Prueba de detección de objetos mediante YOLO utilizando una cámara.

### 03 - Integración YOLO + ESP32
Integración de YOLO con el ESP32 para detectar vehículos y controlar LEDs.

- Carro → LED rojo
- Motocicleta → LED verde
